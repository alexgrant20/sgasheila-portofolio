# Project screenshots

Drop an image here named after the project's `slug` in `src/content/site.ts`, and it replaces
the generated cover on both the card and the popup — no code change needed.

| Project | File to add |
| --- | --- |
| SIAGA | `siaga.png` |
| IGCN | `igcn.png` |
| PISN | `pisn.png` |
| PILN | `piln.png` |
| BIDUK | `biduk.png` |
| BINUS Partner | `binus-partner.png` |
| BINUS Maya | `binus-maya.png` |
| Developer Workspace | `developer-workspace.png` |
| BINUS Career | `binus-career.png` |
| Student Violation | `student-violation.png` |

`.png`, `.jpg`, `.jpeg`, `.webp`, and `.avif` all work. Cards and the popup crop to **16:9**, so
a landscape screenshot around 1280×720 or larger looks best.

A reminder before you add anything: several of these are internal government and university
systems. Only publish screens you are permitted to show, and blur or replace real names, ID
numbers, and other personal data first.
